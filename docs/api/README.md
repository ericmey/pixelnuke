# API Reference

API documentation for Pixelnuke components.

## Status

The API is still under development. Documentation will be added as components are implemented.

## Planned Components

### Audio Engine
- `CSampleVoice` - Individual sample player
- `CDrumKit` - Multi-voice mixer
- Sample loading and playback

### Sequencer
- `CSequencer` - Pattern playback
- Timing and synchronization
- MIDI clock

### User Interface
- `CUI` - Display and button handling
- Menu system
- Visual feedback

### Network
- HTTP API for web interface
- WebSocket for real-time updates

## Circle Framework

Pixelnuke is built on Circle. For low-level APIs, refer to:
- [Circle Documentation](https://circle-rpi.readthedocs.io/)
- [Circle GitHub](https://github.com/rsta2/circle)
